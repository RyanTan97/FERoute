# 737-800 Simulator Route Menu

## Features

### Public Page
- Displays a list of flight simulator routes.
- Shows route name, estimated time, and difficulty level.
- Allows viewing embedded PDF files.

### Admin Page
- Upload new route PDFs.
- Edit route details.
- Download or delete routes.

## Installation
1. Clone the repository.
2. Run `npm install` in the root directory.
3. Start the server with `npm start`.
4. Open the application in your browser.
